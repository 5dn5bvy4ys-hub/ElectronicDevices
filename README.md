# ElectronicDevices
  مشروع الأجهزة الإلكترونية

 فكرة المشروع:
في هذا المشروع درت برنامج بسيط بلغة Java عن الأجهزة الإلكترونية، واستخدمت فيه الـ Interface.

 مكونات المشروع :
المشروع فيه Interface اسمه `Device`، وثلاثة Classes وهي:
- `Phone` يمثل الهاتف.
- `Laptop` يمثل الحاسوب المحمول.
- `Tablet` يمثل الجهاز اللوحي.

كل Class يطبق الـ Interface `Device`.

## الدوال المستخدمة :
استخدمت ثلاث دوال:
- `turnOn()` لتشغيل الجهاز.
- `turnOff()` لإطفاء الجهاز.
- `displayInfo()` لعرض معلومات الجهاز مثل الاسم والسعر.

 طريقة عمل البرنامج :
في كلاس `Main` أنشأت ثلاثة Objects من الكلاسات السابقة، وعطيت كل جهاز اسم العلامة التجارية والسعر، وبعدها عرضت معلومات كل جهاز وجربت دوال التشغيل والإطفاء.

## الهدف من المشروع :
الهدف من المشروع هو فهم كيفية استخدام الـ Interface وتطبيقه في أكثر من Class في Java.

# ElectronicDevices
# مشروع الأجهزة الإلكترونية

## فكرة المشروع
في هذا المشروع درت برنامج بلغة Java عن مجموعة من الأجهزة الإلكترونية، واستخدمت فيه الـ Interface، بحيث يكون عندي Interface واحد وتطبقه أكثر من Class.

## مكونات المشروع
المشروع يحتوي على Interface اسمه `Device` وخمسة Classes:

- `Phone`: يمثل الهاتف.
- `Laptop`: يمثل الحاسوب المحمول.
- `Tablet`: يمثل الجهاز اللوحي.
- `SmartWatch`: يمثل الساعة الذكية.
- `Headphones`: تمثل السماعات.

## الـ Interface
استخدمت `Device` وفيه ثلاث دوال:

- `turnOn()`: لتشغيل الجهاز.
- `turnOff()`: لإطفاء الجهاز.
- `displayInfo()`: لعرض معلومات الجهاز.

## طريقة عمل البرنامج
في كل Class حطيت اسم الشركة والسعر، ودرت Constructor باش نعطي لكل جهاز المعلومات الخاصة به.

وفي كلاس `Main` أنشأت Objects من الأجهزة الخمسة، وبعدها عرضت معلومات كل جهاز وجربت دوال التشغيل والإطفاء.

## الهدف من المشروع
من خلال المشروع هذا تعلمت كيف نستخدم الـ Interface في Java، وكيف نخلي أكثر من Class يطبق نفس الدوال، مع اختلاف كل جهاز عن الثاني.

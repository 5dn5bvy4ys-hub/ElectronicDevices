# Smart Device Center
# مركز الأجهزة الذكية

## فكرة المشروع

في هذا المشروع درت برنامج بلغة Java يحاكي مجموعة من الأجهزة الإلكترونية الذكية، زي الهاتف والحاسوب والتابلت والساعة الذكية والسماعات.

الفكرة من المشروع هي إن كل جهاز يكون عنده وظائف خاصة بيه، بالإضافة إلى الوظائف الأساسية زي التشغيل والإطفاء وعرض المعلومات.

## مكونات المشروع

المشروع يحتوي على Interface وسبعة Classes:

- `Device`: Interface أساسي يحتوي على دوال تشغيل وإطفاء الجهاز وعرض معلوماته.
- `Chargeable`: Interface خاص بالأجهزة اللي تدعم الشحن.
- `Phone`: يمثل الهاتف، ويقدر ينفذ عملية اتصال.
- `Laptop`: يمثل الحاسوب المحمول، ويقدر يشغل البرامج.
- `Tablet`: يمثل الجهاز اللوحي، ويقدر ينفذ عملية الرسم.
- `SmartWatch`: تمثل الساعة الذكية، وتقدر تحسب الخطوات.
- `Headphones`: تمثل السماعات، وتقدر تشغل الموسيقى.
- `DeviceManager`: مسؤول عن إدارة الأجهزة وعرض معلوماتها وتشغيلها وإطفائها.

## طريقة عمل المشروع

في البداية أنشأت Objects من الأجهزة المختلفة، وكل جهاز عنده اسم الشركة والسعر الخاص به، واستخدمت Constructor لإعطاء كل جهاز معلوماته.

بعدها جمعت الأجهزة في Array واحدة من النوع `Device`، واستخدمت كلاس `DeviceManager` للتعامل مع جميع الأجهزة.

البرنامج يعرض معلومات الأجهزة، ويشغلها ويطفيها، ويجرب الوظيفة الخاصة بكل جهاز، بالإضافة إلى تنفيذ عملية الشحن.
